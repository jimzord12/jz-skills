# jz-skills

A personal library of AI-agent skills for software engineering, building toward
agent-powered workflows that cover the whole software development lifecycle — from
discovery and scoping through grilling, specification, TDD slicing, code generation, and
review.

Heavily inspired by, and built on top of,
[Matt Pocock's skills](https://github.com/mattpocock/skills).

## How it's organised

Skills live in three locations, each with a distinct role (the **three-location law**):

| Location | Role |
| --- | --- |
| `.agents/skills/` | **Base skills** — vendored from upstream via `npx skills add`, read-only. |
| `skills/<domain>/<sub>/<name>/` | **My own skills and forks** — the source of truth. |
| `.claude/skills/` | **Generated** symlink view for Claude Code discovery (gitignored). |

See **[CONTRIBUTING.md](./CONTRIBUTING.md)** for the full law: the read-only/fork-before-edit
rules, the discovery sync workflow, versioning, and distribution.

## Install a skill

There's no publish step — the `skills` CLI uses GitHub as the registry. Install any own skill
by its path in this repo:

```sh
npx skills add jimzord12/jz-skills/skills/productivity/cnp
```

Pin to a tag or commit for reproducibility via your own `skills-lock.json`.

## Maintenance

```sh
node scripts/sync-skills.mjs            # regenerate .claude/skills/ discovery view
node scripts/check-skill-versions.mjs   # guard: changed skills must bump metadata.version
node scripts/generate-readme-index.mjs  # regenerate the index below
```
